## 一句话定位

本项目的终局不是传统“Web 刷题网站”，而是一套 **“本地可携带的纯理科知识编译器 + 接入 `pi`（及各类 MCP 客户端）的个性化智能刷题、讲题与错题进化底座”**——把原本没有答案、杂乱且重度依赖配图的原始题目，编译成一张“可数学验真、可算精准难度、可举一反三、且越用越懂学习者”的活知识网络。

## 五大核心闭环能力与当前工程状态

### 1. 无答案/重配图理科题库的“视觉转译 + 数学验真 + 人工护城河”
- **状态**: ✅ 核心基座已落地，当前正执行全量入库
- **能力详情**:
  - VLM 一次性将几何/物理配图转译为纯文本 `visual_facts`（顶点、线段、阴影边界），结合 SymPy 沙盒验算等价性，支持多小问、比值、`ORDERED_TUPLE`/`UNORDERED_MULTISET` 与一题多解多分支；后续纯文本拆解与聚类零重复视觉 Token 消耗。
  - 分歧题或视觉歧义题进入 `NEEDS_REVIEW` 队列，通过用完即关的全键盘本地单页 `shuati review` 同屏核对原图与解法；`human_overrides` 与机器层物理隔离，后续改 Prompt 或换模型重跑不覆盖人工定稿与剔除记录。

### 2. “不掺水”的四维非对称难度标尺 & 多角色动态水平画像
- **状态**: ✅ 题目侧难度引擎已落地 / ⏳ 学习者画像端（M3）待开发
- **能力详情**:
  - 通过 `[C(2^C 指数权重), S, T, L]` 四维正交打分合成 `[800, 2800]` 连续 Elo 并映射为左粗右细 **8 档**（$C \le 2$ 封顶 `L4-A(繁)`，防止繁琐计算题混入竞赛压轴档）。
  - 通过 `learner_id` 隔离各人的 `practice_log`，多人共用同一份题库知识网、各自独立计算分学段/分模块 **通关水位（ZPD 最近发展区）**、8 档通过率曲线（分辨“怕繁”还是“怕巧”）与高危陷阱榜。

### 3. 自底向上“知识树 → 原子算子归并 → 先修依赖网”
- **状态**: ⏳ 下一阶段（M2/M3）待开发（当前 Stage 2 入库已开始沉淀 `raw_l1/l2/l3`、`thinking_methods`、`classic_motifs`、`trap_tags` 候选数据）
- **能力详情**:
  - 汇总全库自然涌现的 `raw_l1/l2` 聚类并经人工一次锁定各学段标准 `L1/L2` 目录树；底层 `L3` 原子算子走半开放可逆并查集归并（发现误合并可无损拆回）。
  - **学段隔离、方法互通**：小学奥数、初中数学、物理、化学各自保持独立知识树与难度标尺；思维技法（`thinking_methods`）、经典母题（`classic_motifs`，如“将军饮马”贯通几何/光学/解析几何）与 6 大数理陷阱（`TRAP_*`）跨学段打通，并自动构建先修有向无环图（DAG）。

### 4. 全库“五边拓扑”举一反三引擎
- **状态**: ⏳ 下一阶段（M3）待开发
- **能力详情**:
  基于四通道指纹（表皮向量、抽象骨架向量、L3+Motif 集合、陷阱集）与难度差，在全库题目间离线织出 5 种关联边：
  1. **`CLONE`（孪生换数）**：去重与 14 天冷却避重；
  2. **`ISOMORPHIC`（换壳同骨）**：场景数字不同但骨架同构，支撑真正跨情境举一反三；
  3. **`SCAFFOLD`（阶梯子母）**：做不出难题时向下找子母铺垫题，掌握后向上拔高；
  4. **`CONTRASTIVE`（形似神异）**：表皮相似但核心模型不同，用于对比辨析；
  5. **`SHARED_TRAP`（同坑共病）**：跨章节同陷阱专项排雷训练。

### 5. 面向 `pi` 的刷题、防剧透讲题、看图打印与“外部错题秒入库”闭环
- **状态**: ⏳ 下一阶段（M4）待开发
- **能力详情**:
  通过 9 个原子 CLI / MCP 能力（`taxonomy`、`search`、`related`、`compose-quiz`、`diagnose`、`ingest-mistake`、`detail`、`log`/`profile`、`render-sheet`）接管日常使用：
  - **智能配卷与避重**：按学习者当前水位自动配出专题小卷（如 2 稳固 + 2 拔高 + 1 陷阱排雷），自动避开近期已独立做对的题目。
  - **防剧透交互与双模式练题单**：默认仅暴露无答案视图与逐步 `hint` 启发；支持一键渲染自包含静态 HTML——屏幕模式带 KaTeX 公式与折叠答案，打印模式（`@media print`）自动每页 2–3 题、保留纸笔画辅助线空白区、答案收至末页。
  - **外部新错题越刷越肥**：遇到库外新题/错题（支持拍照图片），`diagnose` 实时读图提取特征并在本地捞出铺垫题与同构变式题，`ingest-mistake` 直接永久入库并增量接入五边拓扑网。

## 刻意不做的边界（Non-Goals）

- ❌ 不开发常驻型多页面重前端 Web 刷题平台、用户登录鉴权、云端 SaaS 多租户、社交排行或在线手写画板（只保留极简本地审题页 + 静态练题 HTML + CLI/`pi`）。
- ❌ 全部核心资产完全本地自主开放（单文件 SQLite + FTS5 + CAS 图片 + YAML 词表 + 4 份标准 JSONL 导出），不绑定特定云服务或单一模型，可从小学奥数平滑扩展至初中/高中数理化。
