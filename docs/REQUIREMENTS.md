# 纯理科题库与严密知识网系统 — 完整需求规格书（v2.0 定稿）

> **定位**：面向个人及多学习者共用的纯理科离线题库知识编译器与 `pi` 智能检索/刷题助手。
> **理论权威**：[理论基础.md](理论基础.md)（非对称四维难度模型与“剥皮抽骨”五边拓扑理论）。
> **v1 参考归档**：原 Web 刷题系统已归档至 `backup/v1/`，仅作算法代码参考（如难度合成、SymPy 等价验算、并查集与网关封装）。

---

## 一、 系统范围、多角色共用与演进边界

### 1.1 目标学科与演进路径（FR-1）
- **一期（当前存量）**：小学奥数（1000+ 道，JSONL 格式，无标准答案/解析，含大量几何配图，已有粗粒度 `tags` 仅作历史存档）。
- **二期及后续（平滑扩展）**：逐步追加初中数学、初中奥数、初中物理、高中数学、初高中化学等**纯理科**内容，以及日常遇到的外部新错题。
- **多学段隔离与跨学段互通**：
  - **学段隔离**：知识树（`L1/L2/L3`）与难度标尺（`[C, S, T, L]` / `base_elo`）严格按 `grade_subject`（如 `小学奥数`、`初中数学`、`初中物理`）独立作用域管理。
  - **跨学段互通**：思维技法（`thinking_methods`）、经典母题/物理原型（`classic_motifs`，如“将军饮马”贯通小学几何 → 初中光学反射 → 高中解析几何对称最值）与数理陷阱（`trap_tags`）跨学段共享。
- **中学数理化前瞻结构预留**：答案与验真结构在一期即支持**单问 / 多小问（`(1)(2)(3)`）**以及**符号验算（SymPy）/ 非符号定性说理**双轨，二期引入物理电路/实验题与化学方程式题时无需改表返工。

### 1.2 多角色共用支持（FR-11）
- **共享资产、隔离画像**：题库本体、知识网与题目五边关联图全局共享；每个学习者通过 `learner_id`（维护极简 `learners` 注册表，默认 `"default"`）完全隔离各自的做题足迹、分模块 Elo 水位、8 档通过率、薄弱点榜单与组卷避重记录。
- 在 `pi` 中支持按当前默认角色操作，或一句话切换指定角色（如“按某角色的水平组一套几何小卷”）。

### 1.3 明确的非目标（Non-Goals）
- ❌ 不开发复杂常驻型多页面 Web 刷题后台、用户登录鉴权、云端 SaaS 或社交排行；
  *(注：允许提供一个**用完即关的极简本地单页复核脚本**专门服务于离线分歧题人工审校，不构成常驻 Web 业务系统。)*
- ❌ 不内置复杂的双轨 Elo 托管池（Escrow）状态机、每日盲测配额熔断或前端手写画板；
- ❌ 不涉及语文/英语等文科语篇修辞体系；
- ❌ 不在离线批处理解题/打标阶段把原始 JSONL 的 `chapter` 或旧 `tags` 喂给模型（防止章节锚定污染）。

## 二、 核心功能需求明细（FR-2 ~ FR-11）

### FR-2：无答案带几何图题目的“视觉转译 + 独立解题 + 多重验真”
将“看图解题验真”独立为第一阶段硬关口，与后续纯文本拆解/打标彻底解耦：
1. **一次性视觉事实转译（`visual_facts`）**：VLM 先精确提取配图中的全部几何/物理拓扑事实（顶点字母、线面连接、垂直/平行/等长标记、**尤其是阴影区域的精确边界定义**），固化为纯文本落盘，服务于 FTS5 全文检索、`surface` 向量编码与讲题提示。*（注：经 [ARCHITECTURE.md](ARCHITECTURE.md) v2.6 裁决 D-Audit-4，有图题 `has_images=1` 在 Stage 2 深度拆解时同步升级为强制传入原图多模态拆解，并声明人工覆写的 `eff_visual_facts` 具最高权威优先级。）*
2. **双盲交叉求解 + SymPy 符号验算（三道防线）**：
   - **主路 VLM**：仅输入题干 + 配图（严禁传入 `chapter` 与旧 `tags`），输出 `visual_facts`、完整推导、最终答案（支持多小问）及 Python/SymPy 验算脚本；
   - **辅路 VLM（建议跨模型家族）**：独立盲看题干 + 配图，给出思路与最终答案（配置支持 `dual_vlm_policy: "always" | "visual_or_unverified"`，默认 `"always"`）；
   - **确定性核对**：执行 SymPy 脚本自检计算过程，并比对主/辅路答案数学等价性（可参考 `backup/v1/backend/sandbox/sympy_verifier.py`）。
3. **自动捕获“一题多解”**：主/辅两路答案一致但解法路线本质不同时，保留为多分支解法（`branch_1`、`branch_2`），支撑知识网析取（`OR`）路径。
4. **置信度分级**：
   - `VERIFIED_CONSENSUS`：双盲一致且通过验算，自动放行；
   - `NEEDS_REVIEW`：两路答案分歧、验算失败或模型标记图片模糊/阴影歧义，进入人工复核队列；
   - `HUMAN_VERIFIED`：经人工核验或修正后的权威真相。

### FR-3：极简本地键盘复核工具与“人工覆盖层永不丢失”
1. **用完即关的极简本地单页复核工具**：
   - 几十行轻量脚本按需临时启动，只干一件事：拉取 `NEEDS_REVIEW` 队列，**同屏高清展示原图 + 题干 + 左右两路 VLM 解法与答案对比**；
   - 支持全键盘高效操作（`1` 采纳主路 / `2` 采纳辅路 / `E` 手工修正答案或 `visual_facts` / `S` 暂跳过），提交即实时写回 SQLite，审完关掉即可。
2. **人工覆盖层永不丢失（`human_overrides`）**：
   - 机器生成层与人工覆写层分离存储；后续任何 Prompt 升级或换模型重跑流水线，均**严格保留人工确认/修正过的读图描述、答案、解法、难度与标签**。
   - 日常在 `pi` 刷题发现某题有误时，也支持一句话写入人工修正并局部刷新其关联边。

### FR-4：深度题目拆解与多维正交标签体系
基于 Stage 1 验真后的纯文本 `(question, visual_facts, verified_solutions, final_answer)`，拆解互不串味的**五维正交信息**：
1. **最优解步骤骨架（`solution_steps`）**：1～5 个有教学意义的逻辑推理步（合并纯四则代入计算），每步含步骤子目标、核心关系式/公式与挂载的 `L1/L2/L3`；支持多解法分支。
2. **去情境化抽象骨架（`abstract_skeleton`）**：抹除人名、道具与具体数字，用纯学科元语言概括“已知结构 → 核心转化 → 求解目标”。
3. **学段三层知识锚定（`L1 / L2 / L3`）**：
   - `L1`（学科主干模块，每学段收敛至 6～12 个）；
   - `L2`（核心模型/对象/定理群，覆盖同类一族题型）；
   - `L3`（脱壳原子转化算子，4～14 字标准中文短语，不含题干数字字母与道具名）。
   - 支持单题跨模块挂载（如几何×行程综合题），并显式指定整题 `primary_l1_module`。
4. **跨学段方法与经典原型（严禁万金油泛词）**：
   - `thinking_methods`：可操作解题技法（如等积变形、容斥原理、补形割补、比例转化、极端原理），显式黑名单过滤“转化与化归”“逻辑推理”等泛词；
   - `classic_motifs`：严格命中的经典母题/物理原型（如将军饮马、赵爽弦图、蝴蝶模型、鸡兔同笼、斜面滑块等），宁缺毋滥。
5. **数理设错陷阱（`trap_tags`）与纠偏元数据**：
   - `trap_tags`：严格取自 6 大数理陷阱枚举（`TRAP_DOMAIN_BOUNDARY`、`TRAP_SIGN_DIRECTION`、`TRAP_EXTRANEOUS_ROOT`、`TRAP_FRAME_SHIFT`、`TRAP_APPROX_CONDITION`、`TRAP_ARITHMETIC_SLIP`，后续化学可按需增量扩展）；
   - `format`：规则正则 + AI 纠偏题型脏数据（如含 A/B/C/D 选项修正为选择题）；保留原始 `id`、`chapter`、`legacy_tags` 供溯源与新旧对比质检。

### FR-5：整题多维非对称难度评价与分角色水平定位
完整落地 [理论基础.md](理论基础.md) 第一、二部分难度理论（**已确认移除步骤级前缀子难度 `sub_elo`，聚焦整题精准评估**）：

#### 1. 题目侧：整题四维行为打分 + 非线性连续分 + 非对称 8 档
- **防漂移机制**：绑定 `grade_subject` 学段基准；JSON Schema 强制 **`evidence` 排在 `score` 之前**；每学段批跑前标定 **4～5 道黄金基准题**（涵盖 L1/L2、L3、L4-A 繁、L4-B 巧、L5-2 竞赛）作为 Few-Shot 校准锚点。
- **四维正交锚点**：
  - **$C \in [1, 4]$（概念与思维深度，指数权重 $2^C$）**：1=单模型直推；2=单点变形/常规双考点串联；3=跨模块综合/隐式建模；4=非标构造/高阶洞察；
  - **$S \in [1, 3]$（推理链路长度，不含纯算术）**：1=1～2 逻辑步；2=3～4 逻辑步；3=$\ge 5$ 步或多分支分类讨论；
  - **$T \in [1, 3]$（信息隐蔽度与陷阱）**：1=显式透明；2=含隐含条件或需图形/文字转译；3=强反直觉陷阱或极隐蔽临界边界；
  - **$L \in [1, 3]$（运算与审题负荷）**：1=心算/短题干；2=常规纸笔多步演算；3=高繁复计算、多变量联立或高密度信息。
- **确定性代码合成（严禁 LLM 直接输出总分）**：
  - 复用 `backup/v1/backend/services/difficulty_rubric.py` 非线性公式计算连续 `base_elo ∈ [800, 2800]`：
    `base_elo = min(2800, max(800, 750 + 85 * (2^C - 1) + 105 * S + 115 * T + 65 * L))`
  - 映射为左粗右细的非对称 8 档 `tier`（$C \le 2$ 封顶 `L4-A`，杜绝繁琐简单题混入 `L5`）：
    - 低中段：`L1_基础直达`、`L2_常规巩固`、`L3_综合中档`
    - 进阶横向拆解：`L4-A_进阶拔高(繁)` vs `L4-B_进阶拔高(巧)`
    - 顶端高解析度：`L5-1_压轴挑战`、`L5-2_竞赛超难`、`L5-3_殿堂极限`

#### 2. 学习者水平侧：按角色动态派生能力画像
基于指定 `learner_id` 的 `practice_log` 与题目的 `base_elo / tier / primary_l1_module` 实时计算（纯事件派生，零漂移）：
- **分学段 × 分 L1 模块能力水位**：展示该角色在各模块中**独立做对（`SOLVED_SOLO`）**题目的稳定通关水位（如 75 分位 Elo）、历史最高攻克 Elo、以及推荐最近发展区（ZPD：当前水位 $+50 \sim +200$ 分）；
- **8 档难度通过率阶梯**：呈现 `L1 → L5-3` 各档独立正确率，直观分辨“怕繁（`L4-A`）”还是“怕巧（`L4-B`）”；
- **薄弱考点与高危陷阱雷达**：统计历史错题/求助题高频集中的 `L2/L3`、`classic_motifs` 与 `TRAP_*`。

### FR-6：自底向上严密知识网构建（树 → 网）
1. **顶层 L1/L2 自底向上涌现 + 一次人工锁表**：
   - 汇总全库初步拆解产出的 `raw_l1 / raw_l2` 频次，经 Embedding 聚类 + 强推理模型归纳产出《候选目录树 YAML》；
   - 经人工一次审定拍板锁定为标准词表（如 `taxonomy_primary_olympiad.yaml`）；
   - 纯文本批处理将全库精确回填映射至锁定词表，杜绝 L1/L2 碎片化。
2. **底层 L3 算子与原型半开放归并**：
   - 在锁定的同一 `(grade_subject, L1, L2)` 内，经 **Embedding 语义聚类 + 字符 2/3-gram 召回 + AI 裁判确认** 合并同义 L3；
   - 保留 `redirect_to_id` 并查集指针、`aliases` 与 `compaction_audit_ledger` 审计日志，支持发现误合并时一键无损拆回（Un-merge）。
3. **知识点间拓扑边**：
   - **先修依赖有向无环图（Prerequisite DAG）**：结合综合题步骤先后统计 + 强模型梳理 + 自动环检测，建立 `前置知识点 → 进阶知识点` 依赖边；
   - **跨模块耦合共现边**：自动统计综合题中高频共同出现的跨模块知识点对（如“勾股定理 ↔ 比例行程”）。

### FR-7：全库题目四通道五边拓扑织网（“举一反三”引擎）
基于每道题的四通道指纹（表皮向量 $V_{\text{surface}}$、抽象骨架向量 $V_{\text{skeleton}}$、标准 L3+Motif 集合 $K_{\text{set}}$、陷阱集合 $E_{\text{trap}}$）与难度差 $\Delta D$，离线构建 `question_relations`：
1. **`CLONE`（孪生换数）**：高表皮 + 高骨架 + 小难度差 → 查重与同题型热身；
2. **`ISOMORPHIC`（跨域同构）**：低表皮 + 高骨架 → **水平举一反三核心边**；
3. **`SCAFFOLD`（阶梯子母 $A \to B$）**：非对称 Tversky 包含度高且 $D_B - D_A \ge 200$ → **向下降阶铺垫 / 向上升维拔高**；
4. **`CONTRASTIVE`（形似神异）**：高表皮 + 低骨架 → **对比辨析专题**；
5. **`SHARED_TRAP`（同坑共病）**：高陷阱重合 → **跨章节排雷训练**。

### FR-8：多角色极简做题足迹记录表（`practice_log`）
维护轻量追加式做题日志表：
- **核心字段**：`log_id`、`learner_id`（默认 `"default"`）、`question_uid`、`practiced_at`、`outcome`（`SOLVED_SOLO` / `SOLVED_WITH_HINT` / `WRONG` / `SKIPPED`）、`stuck_step_index`（可选）、`user_note`（复盘笔记）。
- 支持单题登记与**整份小卷批量登记**；驱动 FR-5 水平画像、推题自动避重（排除近期已独立做对题）与错题优先回练。

### FR-9：面向 `pi` 终端客户端的检索、组卷、错题入库与看图打印闭环
采用 **“原子 Python CLI + 本地 MCP Server / `pi` Skill + 自包含静态 HTML（屏幕刷题 / 纸笔打印双模式）”** 组合方案：
1. **暴露给 `pi` 的 9 个核心原子能力**：
   - `taxonomy`：浏览某学段知识树、先修依赖、题量及指定角色的掌握热力；
   - `search`：按 `grade_subject / L1 / L2 / L3 / motif / method / trap / tier / elo_range / learner 避重 / 骨架语义` 多维查例题；
   - `related`：沿五边拓扑找降阶铺垫、升维母题、跨域同构、形似神异、同坑排雷题；
   - `compose-quiz`（**一键组专题小卷**）：按指定 `learner_id` 与目标专题/模块当前水位，自动按梯度配卷（例如默认 **5 题 = 2 道稳固 + 2 道拔高 + 1 道薄弱陷阱/形似神异排雷**，支持自定义题量、难度偏好与排除已刷题）；
   - `diagnose`：输入一道**题库之外的新错题（支持本地图片路径）**，实时提取 `visual_facts` + `abstract_skeleton` + 映射到标准知识网与难度，立即匹配出铺垫过渡题与举一反三变式题；
   - `ingest-mistake`（**外部新错题一键收入题库**）：承接 `diagnose` 结果（或直接输入新题），一键落库至 SQLite（图片归档、挂载锁定 L1/L2 与 L3 并查集、增量建五边关联、可选同步记一条 `WRONG` 记录）；
   - `detail`：查看题目详情，**默认 `mode=quiz` 防剧透**（只返题干、配图路径与基础编号，隐藏答案、解析与剧透型 L3/Motif 标签），需要讲题核对时切 `mode=full`；
   - `log` / `log-batch` & `profile`：单题或整套小卷批量登记 `practice_log`，随时查询某角色的分模块水位、8 档通过率与薄弱点雷达；
   - `render-sheet`（**看图 + 打印友好版练习单**）：将任意题单或专题小卷一键渲染为本地自包含静态 HTML：
     - **屏幕模式**：内置 KaTeX 公式渲染 + 高清本地几何配图 + 默认折叠防剧透的“逐步提示 / 标准答案 / 知识点解析”展开按钮；
     - **打印友好版（`@media print`）**：专为纸笔画辅助线优化——每页合理排版 2～3 题、自动在每题下方留出充足空白作图/演算区、隐藏折叠按钮、可选将参考答案与解析独立排版在末页。

### FR-10：脏数据清洗、跨源去重与增量追加演进
- **入库体检与纠偏**：校验每条记录的 `images` 存在性与可读性；自动纠偏错标 `format`（如含 A/B/C/D 选项修正为选择题）；按内容哈希防重复入库，按 `CLONE` 边识别跨教辅孪生换数题。
- **增量追加流程**：
  - 同已有学段追加新题（批量 JSONL 或通过 `ingest-mistake` 单题收入）：增量跑 Stage 1 验真 → 映射至既有 `taxonomy_*.yaml`（遇全新 L2 标记候选待人工批准，L3 走同域对齐/并查集）→ 增量补建五边关联；
  - 新增全新学段/学科（如初中数学/物理/化学）：创建独立 `grade_subject` 作用域与该学段黄金基准题，复用同一流水线自底向上锁定新 `taxonomy_*.yaml`，同时自动接入全局共享的方法/原型/陷阱层。

## 三、 非功能需求（NFR）

1. **NFR-1（资产开放独立）**：主存储为单个本地 **SQLite（含 FTS5）+ 本地向量索引文件 + 资产图片目录 + YAML 标准词表**，并支持一键导出 4 份标准 JSONL（`questions_enriched.jsonl`、`knowledge_nodes.jsonl`、`knowledge_edges.jsonl`、`question_relations.jsonl`）。
2. **NFR-2（断点续跑与成本可控）**：离线批处理按 Stage 落盘缓存，支持并发限流与失败单题重试；Stage 1 与有图题 Stage 2 按需传入原图保障空间精度（v2.6 裁决 D-Audit-4），Stage 3 聚类归并、知识网与 Stage 4 拓扑织网全流程零视觉 Token 消耗。
3. **NFR-3（定量质检审计）**：每次全量或增量编译后自动生成质量体检报告（双盲共识率、SymPy 通过率、8 档难度分布直方图、L3 分布熵收敛度、先修 DAG 无环检测、与旧 `legacy_tags` 差异对比）。
4. **NFR-4（可插拔模型网关）**：统一 OpenAI 兼容接口，支持 Stage 1 主路 VLM、辅路 VLM、Stage 2~3 纯文本模型、Embedding 模型分别独立配置不同模型与端点。
5. **NFR-5（先小样本实证后放量）**：1000+ 题全量批跑前，强制先跑 **25 题几何压力测试**（含阴影、动点、折叠等难图），实测验证读图与解题正确率达标后再放量。
