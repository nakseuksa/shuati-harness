## DEC-029：Windows 隔离沙盒下 `pytest-asyncio` 阻塞根因定位与执行口径

- **背景**：`BypassSandbox: false` 禁网沙盒下运行 `@pytest.mark.asyncio` 用例与本地回环 HTTP 复核页测试时，Python `asyncio.new_event_loop()` 初始化 `ProactorEventLoop._make_self_pipe()` 调用 `socket.socketpair()`（回环 `127.0.0.1` `accept()`）被操作系统禁网拦截导致永久阻塞。
- **裁决结论**：经 `faulthandler` 实证确认为 Windows 沙盒环境限制而非业务代码死锁。同步测试与静态检查继续在沙盒内执行（`ruff --no-cache`、`mypy --cache-dir`）；含 `asyncio` / 本地回环 HTTP 服务器的自动化测试统一在 `BypassSandbox: true` 下运行并留存客观日志。
- **依据**：`worker-verify-llm` `faulthandler` 实证日志与终端沙盒规则。
- **状态**：`EXECUTED`

## DEC-031：红军 Round 2 复检 V1' 沙盒逃逸裁决（Critical 阻断项）

- **背景**：Round 2 复检中 13 项 Round 1 缺陷均已确认关闭（Exit=0），但红军新实证发现 1 项 Critical 级沙盒逃逸 V1'：`sympy.external.import_module(<str>)` 内部调用真实 `builtins.__import__`，且 AST 污点检查可被下标/函数形参/属性链绕过（Repro `repro_m1_r2_sympy_string_eval_bypass_v2.py` 实证可执行 `os.getpid()` / `subprocess.run(...)`）。
- **裁决结论**：裁决为 **Critical 放行阻断项**，责令 `worker-verify-llm` 实施双层纵深封堵：① AST 禁用 `sympy.external`/`utilities`/`interactive`/`testing`/`benchmarks`/`codegen`/`import_module` 等；② 子进程 `_VERIFY_PREAMBLE` 直接替换全局 `builtins.__import__` 并覆写 `sympy.external.import_module`。
- **依据**：`DESIGN.md` §1.2 不变量 6（SymPy 沙盒全平台安全隔离）；Tri-Model 实证纪律 §2.2。
- **状态**：`CLOSED`（Round 3 复跑全部 14 个 Repro 均 Exit=0，红军裁决 `APPROVED`）
