# 任务契约 P8-4：多实体中文「标签+数值」答案等价快路径

- **所属阶段**：Phase 8（真实题库问题修复）
- **权威设计**：`docs/designs/adaptive_practice_harness.md` Target File #6
- **允许修改的文件白名单**：
  - `backend/sandbox/sympy_verifier.py`
  - `tests/test_answer_matching.py`

## 修复目标

解决类似 `\text{鸡 } 40 \text{ 只，兔 } 60 \text{ 只}` 的应用题标准答案因 `latex_to_plain` 整块剥除 `\text{...}` 变成 `"40 60"`，导致用户输入 `鸡40，兔60` 或 `鸡 40 只，兔 60 只` 校验失败的问题：
1. 在 `answers_equivalent` 复合数量快路径之后，增加中文「实体标签 + 数值 + 可选量词」配对检查；
2. 仅当标准答案展开 `\text`/`\mathrm`/`\mbox`/`\operatorname` 后完全由 `(含汉字实体标签, 数值)` 序列构成时生效，绝不干扰代数式、物理单位、复合数量或纯数值判题；
3. 支持乱序但标签与数值一一对应（`兔60，鸡40` ✓）、允许省略/附带“只/个/条”等量词与 `:` / `=` / `有`（`鸡有40只，兔有60只` ✓），允许顺序一致的纯数值列表（`40, 60` ✓），严格拒绝实体数值错位（`鸡60，兔40` ✗）与缺项（`鸡40` ✗）。
