# P6 任务契约：复合数量答案解析修复（9小时36分 误判）

## 上下文
项目：数理自适应刷题 Harness。用户实测报告：题目 `a01b47d7-5d59-5d2f-a666-d97c97b4024f`（小学奥数行程问题）正确答案「9小时36分」，系统判错。
**根因（PM 已取证）**：标准答案存储为 `9\ \text{小时}\ 36\ \text{分}`，`latex_to_plain` 的 `\text{}` 剥离把两个数字直接拼接 → normalize 后变成 **"936"**（9 和 36 拼接）。复合时间量从未被解析，任何正确作答都无法通过。
**注意**：工作树的 `backend/sandbox/sympy_verifier.py` 中已有 PM 预置的解决方案雏形（`_QUANTITY_UNITS` / `_parse_quantity` / `_quantity_equivalent` / `answers_equivalent` 快路径）。你负责**审查、修正、补全**该实现并拥有最终质量；若发现设计缺陷可改进，但必须满足下方全部验收用例。

## 解决方案规格
1. **复合数量解析 `_parse_quantity(text) -> (基本单位值, 量纲) | None`**：
   - 在 normalize 之前解析原始文本（归一化会不可逆地破坏复合量）。
   - 支持：中文单位 + LaTeX `\text{单位}` 包装 + 全角字符 + 多段复合（9小时36分 / 2米30厘米 / 1千克50克）。
   - 量纲与基本单位：时间=分（小时×60、秒÷60）、长度=米、质量=克、货币=元。
   - 「分」歧义：默认时间（分钟）；同串出现 元/角 时按货币（0.01元）。
   - 「9小时36」尾部裸数字按分钟推断（仅限小时后）。
   - 非纯数量文本（方程、符号式、含运算符如 15*m、速率单位 米/秒）必须返回 None，回落既有代数管线。
2. **权威等价路径 `_quantity_equivalent`**：
   - 双方均为数量：同量纲比基本单位值（容差 1e-9 相对）；异量纲 False。
   - 一方数量一方裸数字：裸数字按该量纲任一常用单位表示匹配（时间：小时/分/秒；长度：千米/米/厘米/毫米；质量：吨/千克/克；货币：元/角/分）。
   - **权威判定**：任一方解析为数量时绝不回落 normalize 比对（否则 "936" 会经破损拼接误判通过）。
3. **零漂移约束**：既有判据全部保留——自由符号守卫（5≠7）、反号/常数比率仅限含符号表达式、拉丁单位豁免（15*m 不剥离）、中文尾部单位剥离（20米/秒→20）、裸值对单方程右端。

## 验收用例（必须全部通过，追加到 test_answer_matching.py）
标准答案 = `r"9\ \text{小时}\ 36\ \text{分}"`（= 576 分钟 = 9.6 小时）：

- **拒绝**：`9小时35分`、`10小时`、**`936`（关键！破损拼接值不得通过）**、`9.6分`、`576小时`、`9小时`、`36分`
- 长度/质量：`2米30厘米` ≡ `2.3米`；`230厘米` ≡ `2\ \text{米}\ 30\ \text{厘米}`；`1千克50克` ≡ `1050克`；`2米31厘米` ≠ `2.3米`
